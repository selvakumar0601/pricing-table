# 💳 Pricing Table

A responsive and modern pricing table website built using **HTML5 and CSS3**. This project displays three pricing plans with their prices, features, call-to-action buttons, hover effects, and a highlighted popular plan.

## 🌐 Project Overview

The Pricing Table provides users with a simple way to compare different subscription plans.

The project contains three plans:

- 💼 Basic
- 🚀 Pro
- 👑 Premium

The **Pro** plan is highlighted as the "Most Popular" option.

## ✨ Features

- 📋 Three pricing cards
- 💰 Different pricing plans
- ⭐ Highlighted "Most Popular" plan
- 🎨 Modern and clean user interface
- 🖱️ Button hover effects
- ✨ Pricing card hover animations
- 📱 Fully responsive design
- 📐 CSS Grid layout
- 📱 Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Media Queries
